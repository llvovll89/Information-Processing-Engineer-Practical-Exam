코드 읽기의 기본 상세 학습 →

매번 같은 순서로 푼다
추적표의 열: 실행 줄 / i / 주요 변수 / 배열 / 출력 누적
정수 나눗셈과 나머지
C·Java: -7 / 3 = -2, -7 % 3 = -1. Python: -7 // 3 = -3, -7 % 3 = 2.
연산자·단락 평가
C·Java의 &&와 ||는 결과가 정해지면 오른쪽을 실행하지 않는다. &와 |는 비트 연산과 구별한다.
반복문과 재귀
재귀 함수는 내려갈 때의 호출과 돌아올 때의 계산을 분리한다.
복잡도와 자료구조
DFS는 재귀·스택, BFS는 큐. BST 중위 순회는 키를 정렬된 순서로 방문한다.
트리 순회
루트 A, 왼쪽 B(자식 D,E), 오른쪽 C라면 전위 ABDEC / 중위 DBEAC / 후위 DEBCA.
기본 정렬 알고리즘 손 추적
버블 정렬 1회전 후에는 가장 큰 값이 배열 맨 뒤에 위치한다. 선택 정렬은 한 회전에 교환이 최대 1번뿐이다.

C 언어 상세 학습 →

자료형과 출력
문자 하나는 'A', 문자열은 "A". char s[]="WEB"는 W,E,B,\0의 4칸이다.
포인터 첫걸음
선언의 *는 포인터 선언, 식의 *는 역참조다. p와 *p는 전혀 다르다.
배열과 포인터 산술
int a[3]={4,8,12}; p=a; → *p=4, *(p+2)=12.
증감식 읽는 법
p 변화와 배열 원소 변화를 별도 열에 기록한다.
문자열과 이차원 배열
int a[2][3]에서 a+1은 다음 행, *(*(a+1)+2)는 a[1][2].
함수 인자와 static
일반 지역변수는 호출마다 별개, 지역 static은 생존 기간이 프로그램 전체다.
구조체와 연결 자료구조
연결 리스트에서는 선언 순서가 아니라 next 화살표를 따른다. 트리는 left/right와 재귀 호출 순서를 그린다.
비트 연산과 switch
break가 없으면 다음 case까지 계속 실행되는 fall-through를 확인한다.
문자열 처리 함수
dest 버퍼는 복사·연결 후 결과를 담을 만큼 충분히 커야 한다.

Java 상세 학습 →

실행 뼈대와 타입
정수 나눗셈은 0 방향 절삭. boolean에 0이나 1을 직접 넣지 않는다.
==와 equals
new String("OK") 두 개는 내용이 같아도 별도 객체다. 배열 내용 비교에는 Arrays.equals를 사용한다.
필드 접근과 오버라이딩
Parent p = new Child(); → 필드는 Parent, override 메서드는 Child.
오버로딩과 형 변환
반환 타입만 다르게 해서는 오버로딩이 되지 않는다.
생성자와 초기화
정적 초기화는 클래스 초기화 시 한 번. 인스턴스 필드 초기화와 생성자는 객체마다 수행한다.
static·매개변수·배열
배열 길이는 a.length, 문자열 길이는 s.length().
문자열 +와 예외
print는 줄바꿈 없음, println은 끝에 줄바꿈. finally는 정상 반환·예외 경로에서도 보통 실행된다.
추상 클래스·인터페이스·제네릭
extends / implements / abstract / final을 구별한다. final 변수는 재대입 불가다.
인터페이스의 default·static 메서드
구현 클래스가 default 메서드를 재정의하면 일반 메서드와 같은 동적 바인딩 규칙에 따라 재정의한 쪽이 호출된다.

Python 상세 학습 →

기본 문법과 출력
True, False, None의 대소문자를 지킨다. len(a), type(a), int("12"), str(12)를 읽을 수 있어야 한다.
range와 슬라이싱
range(5,0,-2)는 5,3,1. "ABCDE"[1:5:2]는 "BD".
리스트·튜플·집합·딕셔너리
a.append(x)는 한 원소, a.extend(xs)는 여러 원소를 추가한다. dict.items()는 키와 값의 쌍이다.
별칭과 얕은 복사
[[0]*2]*3은 동일한 내부 리스트를 세 번 참조한다. 독립 행은 [[0]*2 for _ in range(3)].
컴프리헨션과 함수
[x*x for x in range(5) if x%2] → [1,9].
문자열과 딕셔너리 순회
for k in d는 키 순회. k[-1]은 키 문자열의 마지막 문자이고 d[k][0]은 값의 첫 원소다.
논리·정렬·나눗셈
빈 문자열·빈 컨테이너·0·None은 거짓 취급. //는 floor, %는 나눗셈 항등식을 만족한다.
언패킹과 다중 대입
언패킹 대상 개수와 오른쪽 값 개수가 맞아야 한다. * 붙은 이름은 하나만 쓸 수 있다.

SQL 상세 학습 →

문장 종류와 기본 틀
UPDATE t SET col=값 WHERE 조건; DELETE FROM t WHERE 조건; INSERT INTO t(col) VALUES(값);
SELECT 논리 처리 순서
WHERE는 개별 행을, HAVING은 그룹을 거른다. ORDER BY 없이는 출력 순서를 보장하지 않는다.
NULL과 집계
SUM·AVG는 NULL을 제외한다. 값 10,NULL,20의 AVG는 15이다.
조인과 행 개수
같은 키가 왼쪽 2행·오른쪽 3행이면 해당 키의 조인 결과는 6행.
서브쿼리와 집합 연산
부서별 평균보다 큰 급여: e.salary > (SELECT AVG(x.salary) FROM emp x WHERE x.dept=e.dept).
제약조건과 도메인
CREATE DOMAIN score_t AS INTEGER CHECK (VALUE BETWEEN 0 AND 100); PostgreSQL에서 지원하는 예다.
패턴과 뷰·인덱스
LIKE '김%' / ORDER BY score DESC, id ASC / CREATE VIEW v AS SELECT ...
CASE 조건식과 NULL 대체
ELSE를 생략하면 어떤 WHEN도 참이 아닌 행은 NULL이 된다.

데이터베이스 이론 상세 학습 →

관계 모델과 키
최소성은 속성을 하나라도 빼면 더 이상 유일하게 식별하지 못한다는 뜻이다.
무결성과 설계 단계
개념 설계는 ER 모델, 논리 설계는 관계 스키마, 물리 설계는 저장 구조·접근 경로를 구체화한다.
함수 종속과 정규화
복합키 (학번,과목)에서 학번→학생이름은 부분 종속. 학번→학과코드→학과명은 이행 종속의 전형.
BCNF와 분해
R(학생,과목,교수), (학생,과목)→교수, 교수→과목이면 후보키 (학생,과목),(학생,교수). 3NF는 가능하지만 교수는 슈퍼키가 아니므로 BCNF 위반.
ACID와 동시성
Dirty Read는 미커밋 데이터 읽기, Non-repeatable Read는 같은 행 재조회 값 변화, Phantom Read는 같은 조건의 행 집합 변화.
회복·병행 제어·관계대수
관계대수 σ 선택=행, π 추출=열, ⋈ 조인, ÷ 디비전=모든 조건값과 관련된 대상.
NoSQL과 CAP 정리
분할 내성은 분산 환경에서 사실상 항상 고려 대상이므로, 실제로는 분할 상황에서 일관성과 가용성 중 무엇을 우선할지 선택하는 문제로 이해한다.

UML 관계와 다이어그램
일반화는 상속, 실체화는 인터페이스 구현, 연관은 연결, 의존은 사용. 집합은 빈 마름모, 합성은 찬 마름모를 전체 쪽에 표시한다.
응집도와 결합도
순차 응집은 앞 출력이 뒤 입력, 교환 응집은 같은 자료 사용. 스탬프 결합은 구조 전체 전달, 자료 결합은 필요한 자료 전달.
객체지향과 SOLID
DIP는 고수준 정책이 저수준 구현의 구체 클래스에 직접 묶이지 않도록 추상에 의존한다.
생성 패턴 5개
“관련 객체들의 제품군” → Abstract Factory. “복잡한 생성 순서” → Builder.
구조 패턴 7개
“호환되지 않는 API 연결” Adapter / “추상·구현 계층 분리” Bridge / “대리인” Proxy.
행위 패턴 11개
옵저버는 발행자와 구독자, 전략은 정렬·결제 방식 교체, 상태는 상태 변화에 따른 동작 변화로 떠올린다.
UI와 아키텍처
계층형은 책임별 층, 클라이언트-서버는 요청·서비스 분리, 파이프-필터는 처리 단계의 흐름.
이벤트 기반 아키텍처와 CQRS
이벤트 기반 구조는 발행자와 구독자를 느슨하게 결합해 확장에 유리하지만 전체 흐름 추적이 어려워질 수 있다.

테스트 수준과 목적
Verification은 명세에 맞게 만들었는가, Validation은 실제 목적·사용자 요구에 맞는가.
블랙박스 기법
유효 정수 1~100의 경계 후보: 0,1,2,99,100,101.
화이트박스 커버리지
A OR B에 (T,F),(F,T)는 각 조건 T/F를 포함하지만 전체 결과는 두 번 모두 T라 결정 커버리지가 부족하다.
통합 테스트 도구
스텁=호출되는 가짜 하위 모듈, 드라이버=호출해 주는 가짜 상위 모듈.
복잡도·오라클·성능
참 오라클 전체 결과, 샘플링 일부 입력, 휴리스틱 일부+추정, 일관성 이전/다른 결과 비교. 성능은 처리량·응답시간·경과시간·자원 사용률.
품질과 유지보수
수정 유지보수=결함 수정, 적응=환경 변화, 완전=기능·성능 개선, 예방=미래 장애 예방.
정적 분석과 TDD·BDD
TDD 순서: 실패하는 테스트 작성 → 통과시키는 최소 코드 → 리팩터링.

네트워크 상세 학습 →

OSI 7계층
허브 L1, 일반 L2 스위치 L2, 라우터 L3. TCP/IP 4계층은 네트워크 접근·인터넷·전송·응용.
TCP·UDP와 주요 프로토콜
HTTP 80, HTTPS 443, SSH 22, DNS 53, SMTP 25. DNS는 UDP와 TCP 모두 사용. DHCP는 주소 설정, ARP는 로컬 IPv4 주소에 대응하는 링크 계층 주소 확인.
서브넷의 기본
/24=256주소, /26=64주소, /28=16주소. 마지막 옥텟 마스크 192,224,240은 블록 크기 64,32,16.
손으로 계산하는 예
네트워크 .64 / 브로드캐스트 .127 / 호스트 .65~.126 / 사용 가능 62개.
라우팅과 오류·흐름 제어
Stop-and-Wait는 확인 후 다음 전송, Sliding Window는 여러 프레임을 허용. Go-Back-N은 오류 이후 연속 재전송, Selective Repeat는 필요한 것만 재전송.
HDLC와 주소 변환
NAT는 주소 변환, PAT는 포트를 함께 사용. 사설 IPv4: 10/8, 172.16/12, 192.168/16.
URL·가상 네트워크
SDN은 제어 평면과 데이터 평면 분리, NFV는 네트워크 기능을 소프트웨어로 가상화.
HTTP 상태 코드와 무상태성
401은 인증(누구인지) 실패, 403은 인가(권한) 실패로 구분한다.

운영체제 상세 학습 →

프로세스와 스레드
상태: 생성→준비→실행→대기→준비→종료. 문맥 교환은 실행 상태 저장·복구.
스케줄링 공식
HRN 우선순위=(대기+서비스)/서비스. 숫자가 큰 작업을 먼저 선택한다.
SRT 손풀이
대기 A=9-0-6=3, B=3-1-2=0, C=4-2-1=1. 평균 4/3.
페이지 교체
처음 빈 프레임에 적재할 때도 페이지 부재다. LRU는 적중 때도 최근 사용 순서를 바꾼다.
메모리와 교착상태
예방은 조건을 깨기, 회피는 안전 상태 유지(은행가), 탐지는 발생 확인, 회복은 중단·선점 등.
동기화·디스크·RAID
RAID 0 스트라이핑·복구 중복 없음 / 1 미러링 / 5 분산 패리티·디스크 1개 장애 대응 / 6 이중 패리티·2개 장애 대응.
세마포어 동작 추적
뮤텍스는 점유한 주체가 있는 상호배제 도구, 세마포어는 개수 기반의 신호 도구로 구분한다.

보안 목표와 접근통제

관리체계·개발 보안
