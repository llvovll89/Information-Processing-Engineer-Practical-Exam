09

/ · // · % · ** : 기호부터 이해하기

연산자는 계산 방법을 지정하는 기호다. /는 나눗셈, //는 나눈 값을 바닥값으로 내리는 나눗셈, %는 나머지, **는 거듭제곱이다. 7개를 2개씩 묶으면 완전한 묶음은 3개, 남은 것은 1개다. 따라서 7 // 2는 3이고 7 % 2는 1이다.

음수에서는 “소수점만 지운다”는 설명이 틀린다. -7 / 3은 약 -2.333이고, 이 값 이하의 가장 큰 정수는 -3이다. 그래서 -7 // 3은 -3이다. a = (a // b) * b + (a % b)로 검산하면 -7 = -3 * 3 + 2다. 나누는 수가 0이면 예외가 난다.

print(7 / 2, 7 // 2, 7 % 2, 2 ** 3)
print(-7 // 3, -7 % 3)
print(7.0 // 2)
/ · // · % · ** : 기호부터 이해하기 · 한눈에 비교
기호뜻예활용
/일반 나눗셈9 / 2 → 4.5평균
//바닥 나눗셈9 // 2 → 4몫·중간 인덱스
%나머지9 % 2 → 1홀짝·순환
**거듭제곱3 ** 2 → 9제곱
^비트 XOR3 ^ 2 → 1비트 비교

과정으로 이해하기

  1. 첫 줄: 3.5 3 1 8. 각각 나눗셈·바닥 나눗셈·나머지·2의 3제곱이다.
  2. 둘째 줄: -3 2. 음수 몫은 아래로 내리고, 나머지는 등식으로 확인한다.
  3. 셋째 줄: 3.0. //의 수학적 결과와 결과 객체의 자료형을 나누어 생각한다.

답을 가리고 확인

꼭 기억할 것

헷갈리는 지점 Python의 //는 주석이 아니다. 주석은 #이다. 실수가 포함된 7.0 // 2는 정수 객체 3이 아니라 float 3.0이다.

and · or · not과 단락 평가

not은 참·거짓을 뒤집는다. and는 왼쪽이 거짓이면 그 값을 반환하고, 참이면 오른쪽을 평가해 반환한다. or는 왼쪽이 참이면 그 값을 반환하고, 거짓이면 오른쪽을 평가해 반환한다. 따라서 and와 or의 결과가 반드시 bool인 것은 아니다.

우선순위는 비교가 not보다 먼저, 그 다음 and, 마지막 or다. a and b or c는 (a and b) or c로 읽는다. 결과가 이미 정해지면 뒤 함수가 호출되지 않을 수 있다.

print(0 or 7, 3 and 8, not [])
print(False and (1 / 0))

과정으로 이해하기

  1. 첫 줄 7 8 True. 둘째 줄 False: 왼쪽이 거짓이라 1/0을 실행하지 않는다.

답을 가리고 확인

[] or "기본값"의 결과는?

확인 답안 보기

기본값 문자열. 빈 리스트가 거짓이므로 오른쪽을 반환한다.

꼭 기억할 것

0 or 7 → 7 / 3 and 8 → 8 / not [] → True.

헷갈리는 지점 &와 |는 정수에서 비트 연산이다. and와 or로 읽지 않는다.

13

for·while·break·continue·반복 else

for x in 대상은 대상에서 원소를 하나씩 꺼내 x에 넣는다. while 조건은 조건이 참인 동안 반복한다. break는 가장 가까운 반복문 전체를 끝내며 continue는 현재 회차의 남은 부분을 건너뛴다.

반복문에 붙은 else는 break 없이 정상 종료했을 때 실행된다. 반복을 한 번도 하지 않아도 정상 종료라면 실행된다. 중첩 반복문의 break는 안쪽 반복문 하나만 끝낸다.

for i in range(1, 5):
    if i == 2:
        continue
    if i == 4:
        break
    print(i, end=" ")
else:
    print("완료")

과정으로 이해하기

  1. i=1 출력, i=2 건너뜀, i=3 출력, i=4 break. 출력은 끝 공백을 포함한 "1 3 ". 완료는 출력하지 않는다.

답을 가리고 확인

range(2, 7, 2)의 값들은?

확인 답안 보기

2, 4, 6. 7은 포함하지 않는다.

꼭 기억할 것

range(시작, 끝, 간격)의 끝은 포함하지 않는다. while은 종료 조건이 바뀌는지 확인한다.

헷갈리는 지점 for의 else는 if의 else와 다르다. break로 종료하면 실행되지 않는다.

14

인덱스와 슬라이스를 손으로 적기

인덱스는 한 원소의 위치다. 길이 5인 문자열 ABCDE의 인덱스는 0~4, 뒤에서 세는 인덱스는 -5~-1이다. a[-1]은 마지막 원소다. a[start:stop:step]은 여러 원소를 새 시퀀스로 가져오며 stop 위치는 제외한다.

양의 step은 오른쪽, 음의 step은 왼쪽으로 이동한다. 생략한 경계는 이동 방향에 맞는 시작·끝을 사용한다. [::-1]은 마지막부터 처음까지 역순이다. 명시적 -1은 실제 마지막 원소 위치로 해석하므로 [:-1:-1]과 [::-1]은 같지 않다.

s = "ABCDE"
print(s[-1], s[1:4], s[::2], s[::-1])

과정으로 이해하기

  1. 인덱스를 0 A, 1 B, 2 C, 3 D, 4 E로 적는다.
  2. 각 선택 위치는 4 / 1,2,3 / 0,2,4 / 4,3,2,1,0. 출력 E BCD ACE EDCBA.

답을 가리고 확인

"ABCDE"[1:5:2]는?

확인 답안 보기

BD. 위치 1,3만 가져온다.

꼭 기억할 것

ABCDE[1:4] → BCD / [::2] → ACE / [4:0:-2] → EC.

헷갈리는 지점 범위를 벗어난 단일 인덱스는 IndexError, 슬라이스 경계는 조정된다. step=0은 ValueError.

15

리스트 메서드·삭제·반환값

append(x)는 x 하나를 끝에 넣고 extend(대상)는 대상의 원소들을 각각 넣는다. insert(i,x)는 i 위치에 삽입한다. remove(x)는 처음 만나는 값 x를 삭제하고 pop(i)는 i 위치 값을 꺼내 반환하며 삭제한다. pop()은 마지막 값을 꺼낸다.

리스트의 sort(), reverse(), append() 등은 원본을 바꾸고 None을 반환한다. sorted(a)는 새 정렬 리스트를 반환하며 원본을 유지한다. del a[i]는 반환값 없이 삭제하는 문장이다.

a = [1]
a.append([2, 3])
a.extend([4, 5])
x = a.pop()
print(a, x)

과정으로 이해하기

  1. append 뒤 [1,[2,3]], extend 뒤 [1,[2,3],4,5], pop 뒤 [1,[2,3],4]와 반환값 5.

답을 가리고 확인

a=[3,1]; b=sorted(a)의 a와 b는?

확인 답안 보기

a는 [3,1], b는 [1,3].

꼭 기억할 것

append([2,3]) → 중첩 리스트 한 개 추가 / extend([2,3]) → 원소 두 개 추가.

헷갈리는 지점 remove는 인덱스가 아니라 값을 받는다. 없는 값을 remove하면 ValueError.

16

딕셔너리·집합·튜플의 함정

딕셔너리는 키를 값에 대응시키며 같은 키에 다시 대입하면 값을 덮어쓴다. d[k]는 키가 없으면 KeyError, d.get(k,기본값)는 기본값을 반환한다. for k in d는 키, d.items()는 키·값 쌍을 순회한다. 집합은 중복을 없애고 수학적 집합 연산을 지원한다.

튜플은 원소를 다른 값으로 재대입할 수 없는 시퀀스다. 원소 하나짜리 튜플은 (1,)처럼 쉼표가 필요하다. 튜플 안에 리스트가 있으면 그 리스트 자체는 변경할 수 있다. 빈 {}는 딕셔너리, 빈 집합은 set()이다.

d = {"a": 1, "b": 2}
d["a"] = 9
print(d.get("c", 0), "a" in d)
print(sorted({1, 2} ^ {2, 3}))

과정으로 이해하기

  1. 첫 줄 0 True. 둘째 줄 [1, 3]: 둘 중 한 집합에만 있는 값들.

답을 가리고 확인

(3)과 (3,)의 차이는?

확인 답안 보기

(3)은 정수 3, (3,)는 원소 한 개짜리 튜플.

꼭 기억할 것

in은 딕셔너리에서 키 포함 검사. 집합 & 교집합, | 합집합, - 차집합, ^ 대칭차.

헷갈리는 지점 집합 출력·순회 순서를 고정 답으로 암기하지 않는다. 순서가 필요하면 sorted를 쓴다.

17

함수·return·지역 이름·lambda

def는 함수를 정의한다. 매개변수는 호출할 때 인자를 받아 사용하는 이름이다. return은 함수 실행을 끝내고 값을 호출 위치로 돌려준다. print는 화면 출력이며 반환과 다르다. return이 없거나 return만 쓰면 반환값은 None이다.

함수 안에서 대입한 이름은 일반적으로 지역 이름이다. global은 모듈 수준 이름에 대입하겠다는 선언이다. lambda x: x*2는 짧은 함수를 만드는 식이며 별도 return을 쓰지 않는다. sorted(a,key=...)는 key 결과로 정렬하지만 원래 원소를 돌려준다.

def f(x):
    print(x + 1)

r = f(2)
print(r)
print(sorted(["bbb", "a", "cc"], key=lambda s: len(s)))

과정으로 이해하기

  1. f가 3을 출력하지만 반환값은 None. 다음 줄 None, 마지막 줄 ['a', 'cc', 'bbb'].

답을 가리고 확인

return a, b는 어떤 값을 반환하는가?

확인 답안 보기

두 값을 담은 튜플. 호출자가 x,y=f()로 풀어 받을 수 있다.

꼭 기억할 것

인자 → 매개변수 → 본문 → 반환값 → 호출자 순서로 추적한다.

헷갈리는 지점 함수에서 리스트를 수정하는 것과 매개변수 이름을 새 리스트로 재연결하는 것은 다르다.

18

문자열 split·join·replace와 출력 형식

split()은 공백 구간을 기준으로 문자열을 나눠 리스트로 만든다. split(",")는 쉼표를 구분자로 사용한다. "-".join(문자열목록)은 사이에 -를 넣어 합친다. replace(이전,새값)는 교체한 새 문자열을 반환한다.

print(a,b)는 기본 sep=" "로 값 사이에 공백을 넣고 end="\n"으로 줄을 끝낸다. sep와 end를 지정하면 답의 공백·줄바꿈도 달라진다. f"{x:.2f}"는 소수 둘째 자리까지 표시한다.

s = "a,b,c"
print("-".join(s.split(",")))
print(1, 2, sep=":", end="!")
print(3)

과정으로 이해하기

  1. 첫 줄 a-b-c. 다음 출력 1:2!3 뒤 줄바꿈: 두 번째 print가 줄을 바꾸지 않아 세 번째가 붙는다.

문자열은 불변이다. 변환 결과를 대입하지 않으면 원본 이름의 값은 그대로다.

헷갈리는 지점 join의 원소는 문자열이어야 한다. 정수 목록은 str 변환 후 합친다.

19

컴프리헨션·enumerate·zip·map

[식 for x in 대상 if 조건]은 원소를 꺼내 조건을 검사하고 통과한 원소에 식을 계산해 새 리스트를 만든다. enumerate는 (번호,원소), zip은 여러 대상의 같은 위치 원소들을 묶는다. 기본 zip은 가장 짧은 대상이 끝나면 종료한다.

map(함수,대상)은 각 원소에 함수를 적용하는 이터레이터다. list(map(int,["2","3"]))은 [2,3]이다. 이터레이터를 이미 소진하면 다시 순회할 때 값이 남아 있지 않을 수 있다.

print([i * j for i in [1, 2] for j in [3, 4]])
print(list(enumerate(["A", "B"], start=1)))
print(list(zip([1, 2, 3], ["a", "b"])))

과정으로 이해하기

  1. 첫 줄 [3, 4, 6, 8]. i=1에서 j=3,4를 모두 처리한 뒤 i=2로 간다.
  2. 둘째 줄 [(1, 'A'), (2, 'B')], 셋째 줄 [(1, 'a'), (2, 'b')].

답을 가리고 확인

[x for x in range(4) if x%2]는?

확인 답안 보기

[1,3]. 나머지 1은 참이고 0은 거짓.

꼭 기억할 것

중첩 컴프리헨션은 왼쪽 for가 바깥 반복, 오른쪽 for가 안쪽 반복.

헷갈리는 지점 [x if 조건 else y for ...]의 조건식과 [x for ... if 조건]의 필터는 다르다.

==·is·얕은 복사·깊은 복사

==는 값이 같은지, is는 같은 객체인지 검사한다. b=a는 새 리스트를 만들지 않고 같은 객체에 다른 이름을 연결한다. a.copy() 또는 a[:]는 새 바깥 리스트를 만들지만 내부 리스트는 여전히 공유하는 얕은 복사다.

copy.deepcopy(a)는 중첩된 변경 가능한 객체까지 복사할 때 쓴다. 종이에 바깥 리스트와 내부 리스트를 별도의 상자로 그리면 어느 변경이 공유되는지 보인다.

a = [[1], [2]]
b = a.copy()
b[0].append(9)
b.append([3])
print(a)
print(a is b, a[0] is b[0])

과정으로 이해하기

  1. a와 b는 서로 다른 바깥 상자지만 첫 내부 상자를 공유한다.
  2. 출력 [[1, 9], [2]], 다음 줄 False True.
