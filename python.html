Python

슬라이싱·공유 객체·반복을 정확하게

Python 3 기준이다. 문법은 짧지만 얕은 복사와 인덱스 때문에 틀리기 쉽다. 들여쓰기로 실행 범위를 확인한 뒤 리스트가 공유되는지 먼저 그리자.

이번 단원 완료 기준

핵심 규칙을 설명하고, 연습문제의 답과 이유를 해설 없이 적을 수 있으면 체크하세요. 이해 체크와 정답 기록은 별도로 저장됩니다.

01

기본 문법과 출력

블록은 중괄호 대신 들여쓰기로 구분한다. 변수 선언 키워드는 없으며 실행 중 객체에 이름을 연결한다. print(a,b)는 기본적으로 공백으로 구분하고 마지막에 줄바꿈한다.

꼭 기억할 것

True, False, None의 대소문자를 지킨다. len(a), type(a), int("12"), str(12)를 읽을 수 있어야 한다.

헷갈리는 지점 input()의 결과는 문자열이다. 숫자로 계산하려면 변환이 필요하다.

02

range와 슬라이싱

range(start,stop,step)과 a[start:stop:step]은 stop을 포함하지 않는다. a[-1]은 마지막 원소다. a[::-1]은 역순 복사다. 음수 step이면 인덱스가 줄어든다.

꼭 기억할 것

range(5,0,-2)는 5,3,1. "ABCDE"[1:5:2]는 "BD".

헷갈리는 지점 역방향 슬라이스에서 생략한 stop과 명시적 -1은 다르다. 문자열[4:-1:-1]은 빈 문자열이다.

03

리스트·튜플·집합·딕셔너리

list는 순서 있고 변경 가능, tuple은 순서 있고 원소 대입 불가, set은 중복 제거 집합, dict는 key→value 매핑이다. 빈 집합은 set(), {}는 빈 dict다.

꼭 기억할 것

a.append(x)는 한 원소, a.extend(xs)는 여러 원소를 추가한다. dict.items()는 키와 값의 쌍이다.

헷갈리는 지점 집합의 표시 순서를 정답으로 가정하지 않는다. 정렬 결과를 물으려면 sorted(set)을 쓴다.

04

별칭과 얕은 복사

b=a는 같은 리스트를 가리킨다. b=a[:] 또는 a.copy()는 바깥 리스트만 새로 만든다. 안쪽 리스트는 계속 공유할 수 있다.

꼭 기억할 것

[[0]*2]*3은 동일한 내부 리스트를 세 번 참조한다. 독립 행은 [[0]*2 for _ in range(3)].

헷갈리는 지점 복사한 바깥 리스트에 append하는 것과 내부 원소를 바꾸는 것을 구분한다.

05

컴프리헨션과 함수

[식 for 원소 in 반복가능객체 if 조건]은 조건을 통과한 원소만 식으로 바꾼다. 함수는 def로 정의하며 return이 없으면 None이다.

꼭 기억할 것

[x*x for x in range(5) if x%2] → [1,9].

헷갈리는 지점 함수의 기본 인자에 []를 쓰면 함수 정의 때 만들어진 리스트가 호출 사이 공유된다.

06

문자열과 딕셔너리 순회

split은 나누고 join은 구분자로 잇는다. 문자열은 불변이라 replace나 upper 결과를 사용해야 한다. Python 3.7 이상 dict는 삽입 순서를 유지한다.

꼭 기억할 것

for k in d는 키 순회. k[-1]은 키 문자열의 마지막 문자이고 d[k][0]은 값의 첫 원소다.

헷갈리는 지점 기존 키의 값을 갱신해도 그 키의 삽입 위치는 바뀌지 않는다. 없는 키의 d[k]는 KeyError, d.get(k,기본값)은 기본값.

07

논리·정렬·나눗셈

and/or는 항상 bool을 반환하지 않고 평가한 피연산자를 반환할 수 있다. ==는 값 동등성, is는 객체 동일성이다. sorted(a)는 새 리스트, a.sort()는 원본 정렬 후 None을 반환한다.

꼭 기억할 것

빈 문자열·빈 컨테이너·0·None은 거짓 취급. //는 floor, %는 나눗셈 항등식을 만족한다.

헷갈리는 지점 문자열이나 숫자의 값 비교에 is를 쓰지 않는다. 객체 재사용 여부에 따라 우연히 맞는 사례를 외우지 않는다.
