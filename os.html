스케줄링·페이지 교체를 표로 풀기

공식만 외우지 않고 시간축과 프레임 상태를 직접 적는다. 특히 선점 시점과 페이지 적중 때의 갱신 여부가 중요하다.

이번 단원 완료 기준

핵심 규칙을 설명하고, 연습문제의 답과 이유를 해설 없이 적을 수 있으면 체크하세요. 이해 체크와 정답 기록은 별도로 저장됩니다.

01

프로세스와 스레드

프로세스는 실행 중인 프로그램과 자원 단위, 스레드는 실행 흐름 단위다. 같은 프로세스의 스레드는 일반적으로 코드·데이터·힙을 공유하고 각자의 스택과 레지스터 상태를 가진다.

꼭 기억할 것

상태: 생성→준비→실행→대기→준비→종료. 문맥 교환은 실행 상태 저장·복구.

헷갈리는 지점 대기는 CPU를 기다리는 준비 상태와 다르다. I/O 완료를 기다리는 상태다.

02

스케줄링 공식

반환시간=완료-도착, 대기시간=반환-실행시간, 응답시간=최초 실행-도착. FCFS는 도착순, SJF는 짧은 작업 우선 비선점, SRT는 남은 시간이 짧은 작업 우선 선점, RR은 시간 할당량만큼 순환.

꼭 기억할 것

HRN 우선순위=(대기+서비스)/서비스. 숫자가 큰 작업을 먼저 선택한다.

헷갈리는 지점 SRT는 원래 총 실행시간이 아니라 현재 남은 시간을 비교한다. 동률 처리 규칙은 문제 조건을 따른다.

03

SRT 손풀이

A(도착0,실행6), B(도착1,실행2), C(도착2,실행1). 동률은 현재 작업 유지라면 0~1 A,1~3 B,3~4 C,4~9 A. 완료 A9,B3,C4.

꼭 기억할 것

대기 A=9-0-6=3, B=3-1-2=0, C=4-2-1=1. 평균 4/3.

헷갈리는 지점 도착 시점마다 비교하고, 완료되면 대기 중 작업의 남은 시간을 다시 비교한다.

04

페이지 교체

FIFO는 가장 먼저 들어온 페이지, LRU는 가장 오래 사용하지 않은 페이지, LFU는 사용 횟수가 적은 페이지, OPT는 앞으로 가장 늦게 쓸 페이지를 교체한다.

꼭 기억할 것

처음 빈 프레임에 적재할 때도 페이지 부재다. LRU는 적중 때도 최근 사용 순서를 바꾼다.

헷갈리는 지점 FIFO는 적중했다고 적재 순서가 바뀌지 않는다. OPT는 미래 참조열이 있어야 계산할 수 있다.

05

메모리와 교착상태

페이징은 고정 크기, 세그먼테이션은 의미 단위 가변 크기. 내부 단편화는 할당 공간 안 낭비, 외부 단편화는 작은 빈 공간 분산이다. 교착의 필요조건은 상호배제·점유대기·비선점·환형대기다.

꼭 기억할 것

예방은 조건을 깨기, 회피는 안전 상태 유지(은행가), 탐지는 발생 확인, 회복은 중단·선점 등.

헷갈리는 지점 교착 회피와 예방을 같은 뜻으로 쓰지 않는다. 스래싱은 페이지 교체가 과도하여 유효 작업이 줄어드는 현상이다.

06

동기화·디스크·RAID

뮤텍스는 임계구역의 상호배제, 세마포어는 카운터와 대기/해제로 접근을 조절한다. 디스크 SSTF는 가까운 요청, SCAN은 한 방향 이동 후 역방향, C-SCAN은 한 방향 처리 후 되돌아간다.

꼭 기억할 것

RAID 0 스트라이핑·복구 중복 없음 / 1 미러링 / 5 분산 패리티·디스크 1개 장애 대응 / 6 이중 패리티·2개 장애 대응.

헷갈리는 지점 RAID는 백업을 대체하지 않는다. 삭제·오염이 복제되는 것은 별도 문제다.
