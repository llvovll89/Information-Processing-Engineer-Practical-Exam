코드 읽기의 기본

웹 개발 지식을 시험 풀이로 바꾸기

실기는 코드를 직접 실행하기 전에 결과를 예측하는 훈련이 중요하다. 익숙한 JavaScript 규칙을 다른 언어에 그대로 적용하지 말고 자료형, 메모리 공유, 호출 순서, 출력 형식을 분리해서 읽자.

이번 단원 완료 기준

핵심 규칙을 설명하고, 연습문제의 답과 이유를 해설 없이 적을 수 있으면 체크하세요. 이해 체크와 정답 기록은 별도로 저장됩니다.

01

매번 같은 순서로 푼다

① 언어와 출력문을 확인한다. ② 변수의 자료형과 초기값을 적는다. ③ 배열·객체는 별도의 상자로 그리고 참조 화살표를 연결한다. ④ 반복문은 회차별 표를 만든다. ⑤ 함수 호출마다 독립된 지역변수 칸을 만든다. ⑥ 마지막에 출력만 모은다.

꼭 기억할 것

추적표의 열: 실행 줄 / i / 주요 변수 / 배열 / 출력 누적

헷갈리는 지점 머릿속으로 끝까지 계산하면 중간 변경을 놓치기 쉽다. 출력에 공백과 줄바꿈이 있는지 따로 표시한다.

02

정수 나눗셈과 나머지

C와 Java는 정수끼리 /를 하면 0 방향으로 버린 정수다. Python 3의 /는 실수 나눗셈이고 //는 아래쪽 정수로 내린다. JavaScript의 일반 Number 나눗셈과 다르다.

꼭 기억할 것

C·Java: -7 / 3 = -2, -7 % 3 = -1. Python: -7 // 3 = -3, -7 % 3 = 2.

헷갈리는 지점 C에서 double x = 7 / 2;의 x는 3.0이다. 저장할 때 변환해도 이미 잘린 소수 부분은 돌아오지 않는다.

03

연산자·단락 평가

C·Java의 큰 틀은 괄호 → 단항 → 곱셈·나눗셈 → 덧셈 → 시프트 → 비교 → 동등 비교 → 비트 AND/XOR/OR → 논리 AND/OR → 조건 → 대입 순이다. Python은 비트 연산이 비교보다 먼저인 등 순서가 다르므로 이 표를 그대로 적용하지 않는다. 실제 코드는 괄호를 덧그려 해석한다.

꼭 기억할 것

C·Java의 &&와 ||는 결과가 정해지면 오른쪽을 실행하지 않는다. &와 |는 비트 연산과 구별한다.

헷갈리는 지점 Python에는 ++가 없다. ^는 세 언어 모두 거듭제곱이 아니라 XOR이다. Python 거듭제곱은 **.

04

반복문과 재귀

for는 초기화 → 조건 → 본문 → 증감 → 조건 순서다. continue는 현재 본문의 나머지를 건너뛴다. 재귀는 종료 조건과 다음 인자의 크기를 먼저 확인한다.

꼭 기억할 것

재귀 함수는 내려갈 때의 호출과 돌아올 때의 계산을 분리한다.

헷갈리는 지점 C·Java의 for에서 continue 뒤에도 증감식은 실행된다. while에서는 직접 작성한 증감문을 건너뛸 수 있다.

05

복잡도와 자료구조

스택은 LIFO, 큐는 FIFO다. 정렬된 배열의 이진 탐색은 탐색 범위를 절반씩 줄여 O(log n), 전체 순회는 O(n), 독립적인 n회 반복 두 겹은 O(n²)이다.

꼭 기억할 것

DFS는 재귀·스택, BFS는 큐. BST 중위 순회는 키를 정렬된 순서로 방문한다.

헷갈리는 지점 연속한 두 반복문은 O(n)+O(n)=O(n)이다. 중첩 여부와 실제 반복 범위를 확인한다.

06

트리 순회

전위는 루트-왼쪽-오른쪽, 중위는 왼쪽-루트-오른쪽, 후위는 왼쪽-오른쪽-루트다. print가 재귀 호출 앞·사이·뒤 어디에 있는지 표시한다.

꼭 기억할 것

루트 A, 왼쪽 B(자식 D,E), 오른쪽 C라면 전위 ABDEC / 중위 DBEAC / 후위 DEBCA.

헷갈리는 지점 함수 이름이 traverse라고 해서 순회 종류를 알 수 없다. 실제 출력문의 위치로 판정한다.

07

기본 정렬 알고리즘 손 추적

버블 정렬은 인접한 두 원소를 비교해 앞이 크면 교환하는 것을 반복해 매 회전마다 가장 큰 값을 뒤로 확정한다. 선택 정렬은 남은 범위 전체에서 최솟값을 찾아 맨 앞자리와 교환한다. 삽입 정렬은 앞쪽 정렬된 부분에 현재 값을 알맞은 위치로 끼워 넣는다.

꼭 기억할 것

버블 정렬 1회전 후에는 가장 큰 값이 배열 맨 뒤에 위치한다. 선택 정렬은 한 회전에 교환이 최대 1번뿐이다.

헷갈리는 지점 "몇 회전째 상태"를 물으면 전체 정렬 결과가 아니라 그 회전이 끝난 시점의 배열을 정확히 적어야 한다.
