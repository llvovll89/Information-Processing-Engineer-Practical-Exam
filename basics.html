처음 읽는 코드: 변수·값·식·문장

변수는 값을 읽고 변경할 때 쓰는 이름이다. 리터럴은 코드에 직접 적은 값(3, "A")이고 식은 계산해서 값을 만드는 조각(x+2)이다. 대입문은 그 결과를 변수에 저장한다. x=x+1은 방정식이 아니라 이전 x에 1을 더해 새 값으로 바꾸는 명령이다.

순차 실행은 위에서 아래로, 분기는 조건에 따라, 반복은 같은 구간을 여러 번, 함수 호출은 호출된 본문으로 이동했다 돌아오는 흐름이다. 결과를 묻는 문제에서는 각 실행이 끝날 때 변수값을 적는다.

x = 2
x = x + 3
print(x)
x = x * 2
print(x)

진법 변환과 비트의 자리값

배열·스택·큐·연결 리스트

배열은 인덱스로 원소를 찾는 연속 저장 구조다. 연결 리스트는 노드에 값과 다음 노드의 연결을 저장한다. 노드를 찾는 데 순회가 필요하지만 이미 위치를 알면 연결을 바꿔 삽입·삭제할 수 있다.

스택은 마지막에 넣은 것을 먼저 꺼내는 LIFO 구조로 재귀 호출·괄호 검사에 쓴다. 큐는 먼저 넣은 것을 먼저 꺼내는 FIFO 구조로 대기열·BFS에 쓴다. 덱은 양쪽에서 넣고 꺼낼 수 있다.

과정으로 이해하기

  1. 스택에 1,2,3을 넣고 두 번 꺼내면 3,2.
  2. 큐에 1,2,3을 넣고 두 번 꺼내면 1,2.

11

정렬·탐색의 과정과 복잡도

버블 정렬은 인접한 두 값을 비교·교환한다. 선택 정렬은 남은 범위의 최솟값을 골라 앞에 놓고, 삽입 정렬은 현재 값을 이미 정렬된 앞부분의 알맞은 위치에 넣는다. 병합 정렬은 나눠 정렬한 뒤 병합하고 퀵 정렬은 피벗을 기준으로 분할한다.

순차 탐색은 앞에서부터 비교한다. 이진 탐색은 정렬된 범위에서 중간값과 비교해 절반을 버린다. O는 입력 크기가 커질 때 연산량 증가를 표현하며 실제 초 단위 시간이 아니다.

과정으로 이해하기

  1. [3,1,2]의 선택 정렬 첫 회: 최솟값 1과 첫 3 교환 → [1,3,2].
  2. 둘째 회: 남은 3,2에서 2 선택 → [1,2,3].

답을 가리고 확인

한 루프가 n회, 뒤 루프가 n회라면 O(n²)인가?

확인 답안 보기

O(n). 반복 두 개가 중첩되어 각각 n회 수행해야 O(n²)이 된다.

꼭 기억할 것

버블·선택·삽입 평균 O(n²), 병합 O(n log n), 퀵 평균 O(n log n)·최악 O(n²).

헷갈리는 지점 이진 탐색의 전제는 정렬이다. 삽입 정렬은 이미 정렬된 입력에서 O(n)이 될 수 있다.

12

재귀 호출표와 DFS·BFS

재귀는 함수가 자신을 호출하는 것이다. 종료 조건이 없거나 인자가 종료 방향으로 변하지 않으면 끝나지 않는다. 함수마다 인자·지역변수는 따로 존재하며 호출 전 계산과 복귀 후 계산의 순서가 다르다.

DFS는 한 갈래를 깊게 탐색하고 되돌아오며 스택·재귀를 이용한다. BFS는 가까운 거리부터 탐색하며 큐를 이용한다. 그래프에 순환이 있으면 방문 표시가 필요하고, 방문 순서는 인접 노드 선택 조건에 영향을 받는다.

def f(n):
    if n == 0:
        return
    print(n, end="")
    f(n-1)
    print(n, end="")
f(2)

과정으로 이해하기

  1. 내려갈 때 2,1 출력. n=0 종료 후 돌아오며 1,2 출력. 답은 2112.

답을 가리고 확인

간선의 가중치가 모두 같은 그래프에서 가까운 단계부터 탐색하려면?

확인 답안 보기

BFS. 큐를 사용한다.

꼭 기억할 것

재귀는 호출 스택을 그리고, BFS는 큐 내용을 회차별로 적는다.

헷갈리는 지점 가중치가 다른 그래프의 최단 경로에 일반 BFS를 그대로 쓰지 않는다.
