이번 단원 완료 기준

핵심 규칙을 설명하고, 연습문제의 답과 이유를 해설 없이 적을 수 있으면 체크하세요. 이해 체크와 정답 기록은 별도로 저장됩니다.

01

보안 목표와 접근통제

기밀성은 권한 없는 열람 방지, 무결성은 허가 없는 변경 방지·탐지, 가용성은 필요할 때 이용 가능함이다. 인증은 누구인지, 인가는 무엇을 할 수 있는지 판단한다.

꼭 기억할 것

DAC 소유자 재량 / MAC 보안 등급·정책 강제 / RBAC 역할 / ABAC 속성 기반.

헷갈리는 지점 감사 로그·부인 방지·책임 추적은 CIA와 관련되지만 같은 용어가 아니다.

02

암호·해시·전자서명

대칭키는 같은 비밀키로 암복호, 공개키는 키쌍을 사용한다. 해시는 임의 길이 입력을 정해진 길이 값으로 요약하며 역복원을 목적으로 하지 않는다. 전자서명은 개인키로 서명하고 공개키로 검증한다.

꼭 기억할 것

AES 대칭 / RSA 공개키 / SHA-256 해시. 기밀 전송은 수신자 공개키 암호화, 서명은 송신자 개인키 서명.

헷갈리는 지점 해시만으로 송신자 인증이 되지 않는다. MAC/HMAC은 공유 비밀키로 무결성과 인증을 제공한다.

03

웹 공격

SQL Injection은 입력이 SQL 구조에 섞임, XSS는 신뢰하지 않은 스크립트가 브라우저에서 실행됨, CSRF는 사용자 인증 상태를 악용한 요청 유도, SSRF는 서버가 공격자가 유도한 주소로 요청하게 하는 공격이다.

꼭 기억할 것

SQLi는 매개변수화 질의, XSS는 출력 문맥에 맞는 인코딩, CSRF는 토큰·쿠키 정책·출처 검증, SSRF는 대상 제한으로 대응.

헷갈리는 지점 CORS는 인증·인가를 대신하지 않는다. XSS와 CSRF를 “스크립트 공격”으로 뭉뚱그리지 않는다.

04

네트워크 공격

스니핑은 도청, 스푸핑은 위장, 세션 하이재킹은 정상 세션 탈취다. SYN Flood는 반개방 연결 자원 소진, Smurf는 위조된 출발지로 ICMP 반사 증폭, LAND는 출발지·목적지 주소/포트를 동일하게 조작하는 형태다.

꼭 기억할 것

DDoS는 다수 출발지, DRDoS는 반사 서버들을 이용. ARP 스푸핑은 IP-MAC 대응을 속인다.

헷갈리는 지점 공격의 결과가 서비스 거부라고 해서 전부 같은 세부 이름은 아니다. 패킷·주소·연결의 단서를 읽는다.

05

악성코드와 운영 보안

바이러스는 숙주 감염, 웜은 네트워크 자기 전파, 트로이목마는 정상인 척 악성 동작, 랜섬웨어는 암호화 등으로 협박한다. APT는 특정 대상에 장기·지속적 공격, 제로데이는 알려진 대응이 준비되기 전 취약점 악용이다.

꼭 기억할 것

IDS 탐지 / IPS 차단 / WAF 웹 요청 방어 / DLP 정보 유출 방지 / NAC 네트워크 접근통제.

헷갈리는 지점 백신이나 WAF 하나만으로 모든 공격을 막는다고 쓰지 않는다. 통제의 범위가 다르다.

06

관리체계·개발 보안

ISMS는 정보보호 관리체계, ISMS-P는 개인정보 보호까지 통합한다. Secure SDLC는 요구·설계·구현·검증·운영에 보안을 반영한다. 버퍼 오버플로는 경계 밖 쓰기, TOCTOU는 검사와 사용 사이 상태 변화 문제다.

꼭 기억할 것

비밀번호는 평문이나 빠른 단순 해시만으로 보관하지 않고 salt와 적절한 비밀번호 해싱을 사용한다.

헷갈리는 지점 salt는 같은 비밀번호의 동일 해시 노출과 사전 계산 공격을 줄이지만 그 자체가 비밀키는 아니다.

07

신기술 묶음

IaaS는 인프라, PaaS는 실행 플랫폼, SaaS는 완성 서비스. 컨테이너는 호스트 커널을 공유하는 격리, VM은 가상 하드웨어 위 게스트 OS를 실행한다. 엣지는 데이터 발생지 가까이에서 처리한다.

꼭 기억할 것

블록체인=분산 원장·합의·연결 구조 / 디지털 트윈=실물과 대응하는 디지털 모델 / SIEM=보안 이벤트 수집·상관분석.

헷갈리는 지점 클라우드는 운영 책임을 전부 없애지 않는다. 서비스 유형에 따라 사용자의 책임 범위가 달라진다.

08

클라우드 네이티브·생성형 AI 확장 용어

마이크로서비스는 하나의 시스템을 독립 배포 가능한 작은 서비스로 나눈 구조이며, API Gateway는 여러 마이크로서비스 앞단에서 라우팅·인증·속도 제한을 담당하는 단일 진입점이다. 컨테이너 오케스트레이션(쿠버네티스)은 다수 컨테이너의 배포·확장·자동 복구를 관리한다. LLM은 방대한 텍스트로 학습해 다음 토큰을 예측하는 거대 언어 모델이고, RAG(검색 증강 생성)는 답변 전에 외부 문서를 검색해 근거를 덧붙여 환각을 줄이는 기법이다. 제로 트러스트는 내부·외부를 구분하지 않고 모든 접근을 검증한 뒤 최소 권한만 허용하는 보안 모델이다.

꼭 기억할 것

RAG는 모델을 재학습하는 것이 아니라 검색한 문서를 프롬프트에 덧붙여 근거로 쓰는 방식이다. 제로 트러스트의 핵심은 "절대 신뢰하지 말고 항상 검증하라".

헷갈리는 지점 마이크로서비스가 항상 모놀리식보다 빠르다고 일반화하지 않는다. 서비스 호출이 늘면 네트워크 지연이 증가할 수 있다. 방화벽 하나만으로 제로 트러스트를 구현했다고 보지 않는다.
