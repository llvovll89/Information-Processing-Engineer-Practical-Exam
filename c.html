C 언어

주소와 값을 나누면 포인터가 보인다

C는 이 자료에서 가장 먼저 시간을 투자할 영역이다. JavaScript 객체 참조와 비슷한 직관은 도움이 되지만, 주소 산술·배열·문자열 종료 문자는 별도로 배워야 한다. 예제는 C11의 정의된 동작을 기준으로 작성했다.

이번 단원 완료 기준

핵심 규칙을 설명하고, 연습문제의 답과 이유를 해설 없이 적을 수 있으면 체크하세요. 이해 체크와 정답 기록은 별도로 저장됩니다.

01

자료형과 출력

int는 정수, double은 실수, char는 문자 코드 하나를 저장한다. printf의 %d는 int, %c는 문자, %s는 널 종료 문자열, %.2f는 소수 둘째 자리까지 표시한다.

꼭 기억할 것

문자 하나는 'A', 문자열은 "A". char s[]="WEB"는 W,E,B,\0의 4칸이다.

헷갈리는 지점 int의 바이트 수를 무조건 4라고 단정하지 말 것. sizeof 결과는 문제에서 주어진 환경을 따른다.

02

포인터 첫걸음

변수는 값이 놓인 칸, &x는 그 칸의 주소, int *p는 정수 칸의 주소를 저장하는 변수다. *p는 p가 가리키는 칸의 값이다. *p를 변경하면 원본 x가 바뀐다.

int x = 7;
int *p = &x;
*p += 3;  // x가 10이 된다
꼭 기억할 것

선언의 *는 포인터 선언, 식의 *는 역참조다. p와 *p는 전혀 다르다.

헷갈리는 지점 int *p, x;에서 p만 포인터다. x는 정수다.

03

배열과 포인터 산술

a[i]는 *(a+i)와 같은 원소 접근이다. p+1은 1바이트가 아니라 가리키는 자료형 원소 1개만큼 이동한다. 배열 이름은 많은 식에서 첫 원소 주소로 변환되지만 배열 자체와 포인터 변수는 같지 않다.

꼭 기억할 것

int a[3]={4,8,12}; p=a; → *p=4, *(p+2)=12.

헷갈리는 지점 sizeof(a)는 실제 배열 선언이 보이는 곳에서 전체 배열 크기지만 함수의 int a[] 매개변수는 포인터로 조정된다.

04

증감식 읽는 법

*p++는 *(p++)이므로 기존 위치의 값을 사용한 후 포인터가 이동한다. (*p)++는 가리키는 값 자체를 증가시킨다. *++p는 먼저 포인터 이동, ++*p는 먼저 가리키는 값 증가다.

꼭 기억할 것

p 변화와 배열 원소 변화를 별도 열에 기록한다.

헷갈리는 지점 printf("%d %d", i++, i++)처럼 같은 변수의 순서 없는 변경은 C에서 정의되지 않은 동작이다. 임의의 정답을 암기하지 않는다.

05

문자열과 이차원 배열

strlen은 종료 문자 전까지의 길이를 센다. sizeof는 저장 공간을 센다. char s[]는 수정 가능한 배열, 문자열 리터럴을 가리키는 char *를 통한 리터럴 수정은 허용되지 않는다. 이차원 배열은 행 단위로 연속 저장한다.

꼭 기억할 것

int a[2][3]에서 a+1은 다음 행, *(*(a+1)+2)는 a[1][2].

헷갈리는 지점 C 문자열은 +로 이어 붙일 수 없다. 문자열 비교는 strcmp 결과가 0인지 확인한다.

06

함수 인자와 static

모든 함수 인자는 값으로 전달된다. 정수 복사본을 바꿔도 호출자의 정수는 그대로다. 주소의 복사본을 받으면 *p로 호출자의 칸을 바꿀 수 있다. 지역 static은 한 번 초기화하고 호출 사이 값을 유지한다.

꼭 기억할 것

일반 지역변수는 호출마다 별개, 지역 static은 생존 기간이 프로그램 전체다.

헷갈리는 지점 주소를 전달해 원본을 바꾸는 관용 표현을 보고 C 자체가 참조 전달이라고 쓰지 않는다.

07

구조체와 연결 자료구조

struct는 여러 필드를 하나로 묶는다. 변수 n의 필드는 n.value, 구조체 포인터 p의 필드는 p->value로 접근한다. p->value는 (*p).value와 같다.

꼭 기억할 것

연결 리스트에서는 선언 순서가 아니라 next 화살표를 따른다. 트리는 left/right와 재귀 호출 순서를 그린다.

헷갈리는 지점 노드의 값을 교환하는 것과 next 포인터를 바꿔 노드의 순서를 교환하는 것은 다르다.

08

비트 연산과 switch

&는 둘 다 1, |는 하나라도 1, ^는 서로 다르면 1이다. 부호 없는 작은 양수의 <<는 범위 안에서 2의 거듭제곱을 곱하는 효과다. switch는 일치한 case부터 시작한다.

꼭 기억할 것

break가 없으면 다음 case까지 계속 실행되는 fall-through를 확인한다.

헷갈리는 지점 음수 시프트·오버플로·잘못된 시프트 크기는 단순한 산술 규칙으로 풀지 않는다. signed 정수 오버플로는 C에서 정의되지 않는다.

직접 풀어보기 12문제

모두 유형 연습을 위해 직접 만든 문제입니다. C 예제의 printf·strlen은 필요한 표준 헤더가 포함된 상황을 가정합니다. Java는 표시된 클래스·main 위치에서 실행합니다. 단답은 동의어가 있을 수 있어 자동 판정 대신 자기 채점을 사용합니다.
