02

포인터 첫걸음

변수는 값이 놓인 칸, &x는 그 칸의 주소, int *p는 정수 칸의 주소를 저장하는 변수다. *p는 p가 가리키는 칸의 값이다. *p를 변경하면 원본 x가 바뀐다.

int x = 7;
int *p = &x;
*p += 3;  // x가 10이 된다

과정으로 이해하기

  1. x 값 상자에 7을 적는다. p 상자에는 x를 향한 화살표를 그린다.
  2. *p+=3은 화살표 끝의 칸 7을 10으로 바꾼다.
  3. p의 주소값을 3 증가시키는 p+=3과 전혀 다르다.

답을 가리고 확인

p=&x 뒤 *p=9를 실행하면 x는?

확인 답안 보기

9. p는 같은 x 칸을 가리킨다.

꼭 기억할 것

선언의 *는 포인터 선언, 식의 *는 역참조다. p와 *p는 전혀 다르다.

헷갈리는 지점 int *p, x;에서 p만 포인터다. x는 정수다.

10

C 기호 사전과 실행 뼈대

C 프로그램은 main에서 시작하고 중괄호로 블록, 세미콜론으로 대부분의 문장 끝을 표시한다. #include는 헤더의 선언을 사용하게 한다. //와 /* ... */는 주석이어서 출력되지 않는다. 변수는 사용 전에 자료형을 선언한다.

int a=3;은 정수 변수 생성·초기화, a=5;는 변경, a==5는 비교다. &&는 논리 AND, ||는 논리 OR, !는 논리 NOT이다. 조건에서는 0이 거짓이고 0이 아닌 값이 참이다.

#include <stdio.h>
int main(void) {
    int x = 3;
    if (x != 0) { printf("%d", x); }
    return 0;
}

%나머지(printf 문자열 안에서는 형식 시작)

과정으로 이해하기

11

형 변환·정수 나눗셈·문자 코드

정수끼리 /는 소수 부분을 0 방향으로 버린다. (double)a/b는 a를 먼저 실수로 바꿔 실수 나눗셈을 하고 (double)(a/b)는 정수 나눗셈 후 이미 잘린 결과를 실수로 바꾼다. 작은 정수형 char·short는 많은 연산에서 int로 승격된다.

char는 문자 코드를 저장하는 정수형이다. 문제에서 ASCII를 가정한다면 '0'은 48, 'A'는 65다. 숫자 문자 '7'에서 '0'을 빼면 정수 7을 얻는다.

int a=7, b=2;
printf("%.1f %.1f %d", (double)a/b, (double)(a/b), '7'-'0');

과정으로 이해하기

  1. 첫 계산 7.0/2=3.5, 둘째 계산 7/2=3 후 3.0으로 변환. 마지막은 7. 출력 3.5 3.0 7.

-2, -1. -7=(-2)×3+(-1).

꼭 기억할 것

헷갈리는 지점 char의 signed 여부와 int 크기는 구현에 따라 다를 수 있다. 문제 조건을 따른다.

12

전위·후위 증가와 조건·반복

++i는 증가한 새 값을 식에서 사용하고 i++는 이전 값을 식에서 사용하면서 i를 증가시킨다. 독립 문장 i++;와 ++i;는 둘 다 i를 1 증가시킨다. +=, -=, *=는 계산과 대입을 함께 하는 복합 대입이다.

for(초기화;조건;증감)은 초기화를 한 번 한 뒤 조건·본문·증감을 반복한다. while은 먼저 조건 검사, do-while은 본문을 한 번 실행한 뒤 조건 검사한다. switch의 case에서 break가 없으면 뒤 case 본문으로 계속 흐른다.

int i=2;
int a=i++;
int b=++i;
printf("%d %d %d",a,b,i);

과정으로 이해하기

  1. a는 이전 2, 이후 i=3. ++i로 i=4가 되고 b=4. 출력 2 4 4.

답을 가리고 확인

for에서 continue를 만나면 증감식은 실행되는가?

확인 답안 보기

실행된다. 현재 본문의 나머지만 건너뛴다.

꼭 기억할 것

각 문장이 끝난 뒤 i와 대입된 변수를 따로 적는다.

헷갈리는 지점 C에서 같은 스칼라를 순서 없이 여러 번 변경하는 식은 정답을 임의로 추적하지 않는다.

13

배열 초기화·주소·이중 포인터

int a[4]={1,2};는 나머지 원소를 0으로 초기화한다. 지역 배열을 초기화하지 않으면 값을 보장할 수 없다. int *p=a;는 p가 a[0]의 주소를 가리키게 한다. a[i]와 *(a+i)는 같은 원소다.

int **pp=&p;는 포인터 변수 p의 주소를 저장한다. *pp는 p, **pp는 p가 가리키는 int 값이다. 주소를 한 단계 따라갈 때마다 *가 하나 필요하다. 배열 범위 밖을 역참조하면 정의된 출력이 없다.

int x=3;
int *p=&x;
int **pp=&p;
**pp=8;
printf("%d %d", x, *p);

과정으로 이해하기

  1. pp가 p를, p가 x를 가리킨다. **pp=8은 x=8. 출력 8 8.

답을 가리고 확인

int a[4]={1,2};의 a[3]은?

확인 답안 보기

0. 일부만 초기화한 나머지 원소는 0으로 초기화된다.

꼭 기억할 것

주소 화살표 pp → p → x. **pp를 바꾸면 x가 바뀐다.

헷갈리는 지점 배열 바로 뒤의 포인터를 만들 수 있어도 그 위치를 역참조할 수는 없다.

14

문자열 함수·널 문자·입력 주소

문자열은 char 배열에 문자들과 마지막 \0을 저장한다. strlen은 \0 전까지 문자 개수, strcpy는 종료 문자까지 복사, strcat는 끝에 붙이고 strcmp는 사전순 비교 결과가 음수·0·양수인지 알려준다. 목적지에는 충분한 공간이 필요하다.

scanf("%d", &x)는 읽은 값을 x에 저장하려고 주소를 받는다. char s[20]에 scanf("%19s",s)는 첫 원소 주소를 전달한다. %s는 공백 전까지 읽으므로 한 줄 전체 입력과 다르다.

char s[10]="AB";
strcat(s,"CD");
printf("%s %zu",s,strlen(s));

과정으로 이해하기

  1. A,B 뒤의 종료 위치에 C,D,\0을 붙인다. 출력 ABCD 4. 저장 공간은 여전히 10칸.

답을 가리고 확인

char s[]="A";의 sizeof(s)와 strlen(s)는?

확인 답안 보기

2와 1. sizeof에는 종료 문자 공간이 포함된다.

꼭 기억할 것

strcmp(a,b)==0이면 내용이 같다. strcmp가 반드시 -1 또는 1을 반환하는 것은 아니다.

헷갈리는 지점 문자열 리터럴 수정, 작은 버퍼에 복사, 종료 문자 없는 배열의 strlen은 안전한 출력 문제가 아니다.

15

지역·전역·static과 메모리 수명

지역 자동 변수는 블록 실행 동안 존재하고 초기화하지 않은 값은 보장하지 않는다. 전역 변수와 정적 저장 기간 변수는 명시적 초기화가 없으면 0으로 초기화된다. 지역 static은 블록 안에서 이름을 사용하지만 호출 사이 값을 유지한다.

malloc은 동적 저장 공간을 할당하고 실패하면 NULL을 반환한다. calloc은 할당 공간을 모두 0비트로 초기화한다. free는 할당한 공간을 해제한다. 함수 지역 자동 변수의 주소를 반환하면 함수 종료 후 그 객체를 사용할 수 없다.

int f(void) {
    int a=0;
    static int b=0;
    a++; b++;
    return a+b;
}
// f()를 순서대로 두 번 호출하면 2, 3

과정으로 이해하기

  1. 첫 호출 a=1,b=1. 둘째 호출 a는 새로 0에서 시작해 1, b는 기존 1에서 2.

답을 가리고 확인

static 지역변수는 전역에서 이름으로 접근할 수 있는가?

확인 답안 보기

아니다. 수명은 프로그램 전체지만 이름의 범위는 해당 블록이다.

꼭 기억할 것

이름의 보이는 범위(scope)와 객체의 생존 기간(lifetime)은 별개다.

헷갈리는 지점 free 후 접근·중복 해제·초기화 안 된 지역 변수 읽기의 결과를 고정 숫자로 외우지 않는다.
