네트워크

계층·프로토콜·서브넷 계산

웹의 HTTP 경험을 IP·링크 계층까지 확장한다. 주소 문제는 네트워크 주소, 브로드캐스트 주소, 사용 가능한 호스트 범위를 따로 적는다.

이번 단원 완료 기준

핵심 규칙을 설명하고, 연습문제의 답과 이유를 해설 없이 적을 수 있으면 체크하세요. 이해 체크와 정답 기록은 별도로 저장됩니다.

01

OSI 7계층

물리 비트·전송 매체 / 데이터링크 프레임·MAC / 네트워크 패킷·IP·라우팅 / 전송 세그먼트·포트·종단 통신 / 세션 대화 관리 / 표현 형식·암호화·압축 / 응용 사용자 서비스로 기억한다.

꼭 기억할 것

허브 L1, 일반 L2 스위치 L2, 라우터 L3. TCP/IP 4계층은 네트워크 접근·인터넷·전송·응용.

헷갈리는 지점 실제 장비는 여러 계층 기능을 통합할 수 있다. 문제에 별도 조건이 없다면 전통적 분류로 푼다.

02

TCP·UDP와 주요 프로토콜

TCP는 연결 기반·순서·재전송·흐름 제어, UDP는 비연결 데이터그램으로 자체 신뢰성 보장이 없다. TCP 연결은 SYN → SYN/ACK → ACK.

꼭 기억할 것

HTTP 80, HTTPS 443, SSH 22, DNS 53, SMTP 25. DNS는 UDP와 TCP 모두 사용. DHCP는 주소 설정, ARP는 로컬 IPv4 주소에 대응하는 링크 계층 주소 확인.

헷갈리는 지점 HTTPS라고 항상 TCP만 쓰는 것은 아니다. HTTP/3는 QUIC/UDP를 사용한다. 시험이 묻는 프로토콜 범위를 확인한다.

03

서브넷의 기본

IPv4는 32비트. /p의 주소 수는 2^(32-p). 보통의 서브넷에서 호스트 수는 전체-2다. 네트워크 주소는 IP AND 마스크, 브로드캐스트는 호스트 비트 전부 1이다.

꼭 기억할 것

/24=256주소, /26=64주소, /28=16주소. 마지막 옥텟 마스크 192,224,240은 블록 크기 64,32,16.

헷갈리는 지점 /31 점대점과 /32는 일반적인 -2 규칙의 예외다. 서브넷의 크기와 사용 가능한 호스트 수를 구별한다.

04

손으로 계산하는 예

192.168.4.77/26: 블록 크기 64이므로 구간은 0~63,64~127,128~191,192~255. 77은 64~127에 속한다.

꼭 기억할 것

네트워크 .64 / 브로드캐스트 .127 / 호스트 .65~.126 / 사용 가능 62개.

헷갈리는 지점 주어진 IP에 무조건 1을 빼서 네트워크 주소를 만들지 않는다. /23에서는 세 번째 옥텟 경계도 계산해야 한다.

05

라우팅과 오류·흐름 제어

RIP는 거리 벡터·홉 수, OSPF는 링크 상태·다익스트라, BGP는 AS 사이 경로 벡터다. CRC는 다항식 나눗셈의 나머지로 오류를 검출한다.

꼭 기억할 것

Stop-and-Wait는 확인 후 다음 전송, Sliding Window는 여러 프레임을 허용. Go-Back-N은 오류 이후 연속 재전송, Selective Repeat는 필요한 것만 재전송.

헷갈리는 지점 CRC는 오류 검출이지 암호화·인증이 아니다. RIP의 16홉은 도달 불가다.

06

HDLC와 주소 변환

HDLC의 I 프레임은 정보, S는 감독·흐름/오류 제어, U는 비번호 제어다. ABM은 대등한 복합국, NRM은 주국 허가에 따른 종국 응답, ARM은 종국이 허가 없이 응답할 수 있는 모드다.

꼭 기억할 것

NAT는 주소 변환, PAT는 포트를 함께 사용. 사설 IPv4: 10/8, 172.16/12, 192.168/16.

헷갈리는 지점 172.x 전체가 사설은 아니다. 172.16.0.0~172.31.255.255 범위다.

07

URL·가상 네트워크

https://example.test:8443/a?q=1#part에서 scheme=https, authority=example.test:8443, path=/a, query=q=1, fragment=part다. VPN은 공중망 위 논리 사설 연결, VLAN은 링크 계층 논리 분리다.

꼭 기억할 것

SDN은 제어 평면과 데이터 평면 분리, NFV는 네트워크 기능을 소프트웨어로 가상화.

헷갈리는 지점 fragment는 일반적인 HTTP 요청의 대상 경로에 전송되지 않고 클라이언트에서 해석된다.
