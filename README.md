# 정보처리기사 실기 공부방

시작: index.html을 Chrome 또는 Edge로 열기. 설치와 로그인은 필요하지 않습니다.

- 12개 학습 단원, 182개 개념, 191개 창작 문제
- 기호 풀이·예제 과정·비교표·모든 개념의 회상 질문 (2026-10-14 추가 보강)
- 2024~2026 공개 복원 8회차의 대표 주제 지도
- 2026-10-14~2026-10-24 11일 계획 (20분 최소 / 45~90분 확장)
- 검색, 자기 채점, 오답 필터, 진도/답안 저장, JSON 백업, 인쇄
- 20문항/150분 학습용 모의 연습 (새로고침 시 모의 구성과 타이머 초기화)

공식 원문 기출 전체 수록본이 아닙니다. 출처·검증 범위는 sources.html을 확인하세요.

## 파일
HTML/CSS/JS 파일을 같은 폴더에 두세요. 인터넷 없이 학습 가능하며 외부 출처 접속만 인터넷이 필요합니다.

브라우저별 file:// localStorage 정책이 다르므로 학습 기록은 홈에서 주기적으로 백업하세요. 폴더 이동 시 기록이 공유되지 않을 수 있습니다. 안정적인 사용은 Node가 설치된 환경에서 `node serve.js` 후 http://127.0.0.1:4173 을 여는 방법도 있습니다.

## 수정과 재생성
sprint-content.js: 10월 14일 보강 / sprint-pages.js: 11일 계획·요약 / content.js: 기존 학습 콘텐츠 / supplement.js: 기초·상세 보강 / lesson-render.js: 설명·비교표·회상 렌더링 / build.js: HTML 생성 / app.js: 학습 기능 / styles.css: 화면

`node build.js`로 정적 HTML과 검색·문제 데이터를 재생성합니다.

## 11일 집중 학습

홈 → 11일 계획 → 오늘 문제 → 시험 직전 압축본 순서로 이용하세요. 출장 중에는 20분 최소 분량, 여유가 있으면 45~90분 확장 분량을 선택합니다. 압축본에서 답을 가리는 회상 모드로 전환할 수 있습니다. 기존 진도와 11일 계획은 분리해서 집계하고 같은 JSON 백업으로 옮길 수 있습니다.

새 글자를 추가했다면 `node build.js` 다음 `py -3 subset-font.py`로 경량 글꼴을 다시 만드세요(fonttools·brotli 필요). 원본 글꼴·라이선스는 fonts 폴더에 보존합니다. 실행·구조 검증: `node verify.cjs`, `node verify-content.cjs`, `node verify-sprint.cjs`.
